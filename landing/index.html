Daftar kost, lewat satu API kecil.

go-kos-api adalah REST API Go + Fiber untuk listing kost: filter lokasi dan harga, tambah, ubah, hapus. Satu perintah untuk jalan, tanpa database.

Demo interaktif

Coba filter dan tambah kos — langsung di browser, memakai data contoh yang sama dengan seed API.

Demo ini berjalan sepenuhnya di browser. Data yang ditambahkan hanya ada di halaman ini dan hilang saat refresh — sama seperti API aslinya yang menyimpan data di memori.

Endpoint

Semua respons sukses: {"status": "success", "data": ...}. Semua error: {"error": "pesan"}.

MethodEndpointFungsi
GET/healthCek server hidup
GET/api/kosDaftar semua kos
GET/api/kos?lokasi=kampusFilter lokasi (substring, case-insensitive)
GET/api/kos?min_harga=&max_harga=Filter rentang harga/bulan
GET/api/kos/:idSatu kos (404 bila tidak ada, 400 bila id bukan angka)
POST/api/kosTambah kos (nama wajib, harga > 0)
PUT/api/kos/:idUbah kos
DELETE/api/kos/:idHapus kos (204)

Mulai dalam satu menit

Butuh Go 1.26+ dan tidak butuh apa-apa lagi.

# clone & jalankan
git clone https://github.com/dezzorigin/go-kos-api.git
cd go-kos-api
go run .
# server jalan di http://localhost:8080

# port lain
PORT=3000 go run .

# tes
go test -race -cover ./...

Filter beneran

Lokasi dicocokkan substring tanpa peduli huruf besar/kecil; harga difilter min–max. Nilai bukan angka ditolak 400.

CRUD lengkap

List, get, create, update, delete. ID baru = max ID + 1, jadi tidak tabrakan setelah ada yang dihapus.

Teruji & rapi

go test -race hijau, coverage 80,6%. CI: gofmt, vet, build, golangci-lint, html-validate.

Batasan jujur: data hanya di memori (hilang saat server berhenti) dan belum ada autentikasi — jangan expose langsung ke internet tanpa auth di depannya. Detail ada di README repo.
